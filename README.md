# Study planner
## Project Description
The study planner is a webpage that enables one to keep track of numerous assignments. It therefore helps a student to organize and plan accordingly basing on their workload at that particular moment

## Setup Instructions
Clone the repository:
1. git clone https://github.com/tevnjau/study-plann
2. Open the project folder.
3. Open index.html in your web browser.
4. Fill in the form with the name of the assignment, the day assigned and the level of urgency.
5. Click Add Place to add it to your list. Each entry can be deleted if needed.

---

## Functionality
The webpage is user-centric:
Given a user opens the Study planner web page
When they enter the assignment, the day assigned and the level of urgency.
Then the app creates a new place card and displays it on the page
And if any required fields are missing, the app alerts the user
And each place card can be deleted by clicking the Delete button
